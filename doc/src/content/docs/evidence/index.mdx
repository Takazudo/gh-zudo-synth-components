This edition retains **53 distinct PDF files**. It contains 105 inherited/historical source-metadata records; some records share a file, and others are links or project-state sources only. A PDF count is not a count of qualified components.

Every retained PDF passed a magic-header, SHA-256 and parser-open check. That is an acquisition/usability check, not a renewed audit of every figure and rating. Source facts keep their originating locators and conditions. Original acquisition dates are not changed to today.

`provenance/source-files.json` maps each hash to a local path and original source location. `corpus/source-records.json` maps component source IDs to retained bytes where a hash match exists. Raw PDFs stay outside `doc/public`; the site links their original URLs.
