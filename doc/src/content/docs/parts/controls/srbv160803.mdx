## Why it is useful

This is a maintained rotary selector, not a continuous potentiometer. It can select a reference ladder or coded state for repeatable octave steps, while a separate continuous control handles tuning.

## Design cautions

Body envelope, support features, asymmetric pin geometry, rotation, bushing and shaft indexing must all be checked. In the source instrument a fixed-centre multi-plane adapter was considered; that is a project-specific solution, not evidence that this selector fits every 17 mm lane. Never convert a mounting-hole diameter into an assumed solid-leg diameter.
