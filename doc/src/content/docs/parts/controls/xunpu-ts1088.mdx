## Why it is useful

This smaller button was considered for a near-panel button PCB. It can be useful when a guided pressing surface decouples the fingertip target from the electrical-switch footprint.

## Design cautions

Actuator height and panel/plunger tolerances must be selected as an assembly. The small electrical switch is not a finished performance button.
