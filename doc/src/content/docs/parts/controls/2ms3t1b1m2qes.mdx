## Why it is useful

The matching T1-lever ON–OFF–ON direction gives three maintained mechanical positions for functions such as ASR/AR/LOOP or SOFT/OFF/HARD. The centre-open contact condition can be decoded as an active operating mode.

## Design cautions

Do not use the two-position C908280 as a substitute. The centre needs deliberate pull-up/pull-down or analog default circuitry, and the unpowered state must remain defined. The source retains unresolved exact-suffix equivalence; Thonk DW2 is a sourcing lead, not a universal code for all Dailywell variants.
