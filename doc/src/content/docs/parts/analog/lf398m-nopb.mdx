## Why it is useful

LF398M/NOPB was chosen as a first sample-and-hold implementation candidate. This M/NOPB version uses SOIC-14; an eight-pin DIP drawing is not its package pin map.

## Design cautions

Keep the hold capacitor and sensitive node local. Larger capacitance can reduce droop but lengthen acquisition. Offset, hold step, leakage and temperature matter for pitch storage. Slew must follow a buffered held output rather than loading the storage node.
