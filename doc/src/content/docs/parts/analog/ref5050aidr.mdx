## Why it is useful

REF5050AIDR supplies a precision 5 V reference basis for control scaling or calibrated reference networks. It is not the same thing as a general 5 V power rail.

## Design cautions

Check input headroom, load regulation, capacitor stability and return routing. Buffer large fanouts and keep sense/return references deliberate. Multiple remote control loads can create errors even when the reference IC itself meets its datasheet.
