## Why it is useful

CD74HC221M96 is the non-retriggerable one-shot candidate used to turn a trigger event into a controlled acquisition window for each sample-and-hold channel.

## Design cautions

Pulse width depends on the specified external timing network and operating conditions. Confirm trigger polarity, reset behavior and pulse completion. A long gate wired directly to a track/hold control would track continuously instead of capturing a single destination.
