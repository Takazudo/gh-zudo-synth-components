## Why it is useful

SN74HC74DR provides D-type state storage useful in deterministic envelope/control logic. It is a building block for explicit state, not a complete envelope generator.

## Design cautions

Clock, asynchronous set/reset priority, startup state and setup/hold behavior need a circuit contract. A browser demonstration of ASR/AR/loop behavior cannot substitute for these hardware transitions.
