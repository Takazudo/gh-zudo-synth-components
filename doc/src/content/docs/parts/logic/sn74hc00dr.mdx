## Why it is useful

SN74HC00DR can implement gating and interlocks in envelope control without firmware. Its value is in a documented truth table and predictable input levels.

## Design cautions

Terminate unused inputs, define power-up behavior and analyze glitches when multiple signals change together. Do not use arbitrary logic delays as the only guarantee of a sampling or reset pulse.
