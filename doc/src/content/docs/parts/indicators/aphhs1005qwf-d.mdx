## Why it is useful

The 0402 white emitter was introduced when larger indicator packages conflicted with the dense jack/pot layout. A smaller light source can reduce the PCB courtyard while preserving the front-panel light window.

## Design cautions

The package height and optical path still matter. Maximum continuous current is not a recommended brightness target. Qualify current limiting at the actual hot ambient, aperture coupling, light bleed and the separately mounted stage-LED plane.
