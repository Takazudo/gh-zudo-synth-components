# One-time corpus import

This branch is temporary transport and build tooling for the owner-requested import of the existing Modular Synth Component Corpus v0.1.0. The final source branch is created separately from the repository's initial main commit.

Use the exact pinned source files where the handoff retained them, apply the corpus-authored overlay, recover original CAD/datasheets only on matching SHA-256, and regenerate derived output with the locked toolchain. Do not reinterpret old component evidence as new electrical qualification.

No deployment, source-repository modification, purchase, or fabrication action is included.
