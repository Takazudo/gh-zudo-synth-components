# Modular Synth Component Corpus

Repository for the reusable modular-synth component library developed from OSC Hole Field research.

The initial import is being prepared on a separate branch. It contains the zudo-circuit-doc project, authored component and application research, retained source evidence and scoped 3D previews. Generated build output and dependency folders are not source-controlled.

This is a research corpus, not a fitted BOM or a manufacturing release. Datasheets and CAD retain their original rights and qualification limits.
