# Source rights and publication boundary

This library contains different classes of material. They do not share one blanket
license.

- Newly authored corpus notes and tooling are project material for the owner.
- zudo-circuit-doc / zudo-doc and bundled JavaScript retain their own package
  licenses. Three.js and esbuild notices are in `third-party-notices/`.
- Manufacturer datasheets, drawings and ALPS STEP files retain manufacturer rights.
  The original ALPS Read-me-first files remain beside the retained CAD.
- The PJ398SM model is community-family geometry from the pinned AudioJacks source.
  Its original MIT notice is retained in the history asset folder.
- Existing drawing-derived WRL proxies and footprint previews retain their
  inherited source/project attribution; they are not newly vendor-certified CAD.

The full local package includes source PDFs for reference. The static site's
public directory does not mirror that PDF collection or expose a source download
endpoint. The interactive browser contains viewing meshes. Neither this separation
nor a successful framework publication check establishes redistribution permission.

Before public deployment, review each selected asset's terms and source notices.
Keep original source URLs available, remove viewing assets without sufficient
permission, and retain the text-only research profile rather than replacing it
with an invented model. No public deployment occurred in this edition.
